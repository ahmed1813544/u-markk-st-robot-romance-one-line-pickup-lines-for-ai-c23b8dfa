## The line

> Are you a CAPTCHA? Because every time I try to prove I'm human, I keep picking you.

## How it works

`main.py` (Python 3.13, stdlib only) writes the single pickup line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR`, or
`/output/entry.txt` by default. The output is deterministic: every run
writes the same bytes.

```sh
python3 main.py
```
